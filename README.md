## Sobre este repositório

Este é o ponto de partida do meu portfólio profissional em TI. A ideia é centralizar aqui, de forma organizada, tudo o que produzo ao longo da graduação — desde anotações de disciplinas até projetos práticos — construindo um histórico consistente da minha evolução técnica.
